# Калькулятор жаропонижающих - Полное описание функционала

## Общее описание
Flutter веб-приложение для расчета дозировок жаропонижающих препаратов для детей с учетом возраста и веса, ведения истории температуры и приема лекарств.

## Основные функции

### 1. Управление семьей
- **Добавление членов семьи** с указанием имени, возраста (лет/месяцев) и веса
- **Отображение полной информации** в карточке: имя, вес и возраст
- **Автоматическая проверка веса** по возрастным нормам с предупреждениями:
  - **1-11 месяцев**: индивидуальные диапазоны для каждого месяца (2-12кг)
  - **1-5 лет**: диапазоны по годам (8-24кг)
  - **6-17 лет**: диапазоны по годам (16-90кг)
- **Редактирование** имени и веса существующих карточек
- **Удаление** карточек с подтверждением
- **Автосохранение** всех данных локально (SharedPreferences)

### 2. Мониторинг температуры
- **Запись температуры** (26-43°C) с умными рекомендациями по возрастам:
  - **До года (0-11 мес)**: 7 диапазонов от переохлаждения до критических значений
  - **1-5 лет**: 6 диапазонов с учетом подгузников
  - **6-17 лет**: 6 диапазонов без упоминания подгузников
  - **Старше 17 лет**: предупреждения о критических значениях
- **Интерактивный график** температуры за последние 24 часа (4-часовое окно)
- **Увеличенные маркеры** лекарств на графике (в 1.5 раза крупнее)
- **Умное позиционирование** маркеров: выше температурных точек при совпадении времени
- **Проверка интервалов** - предупреждение при измерении раньше 1.5 часов после лекарства
- **Адаптивные границы** графика (35-40°C с расширением при необходимости)

### 3. Система жаропонижающих
#### Ибупрофен (5 форм с точными дозировками):
- **Суспензия 100мг/5мл** (3-40кг): минимальная/оптимальная доза в мл
- **Суспензия Форте 200мг/5мл** (3-40кг): минимальная/оптимальная доза в мл
- **Свечи 60мг** (3-13кг): точная дозировка в свечах
- **Свечи 125мг** (7-29кг): точная дозировка в свечах
- **Таблетки 200мг** (10-40кг): рекомендуемая/максимальная доза

#### Парацетамол:
- Базовые расчеты реализованы, формы препаратов в разработке

### 4. Пользовательские лекарства
- **Быстрая отметка** приема любого лекарства
- **Создание курсов** с настройкой:
  - Количество приемов в день (1-6)
  - Время каждого приема (настраиваемые часы/минуты)
  - Продолжительность курса (1-30 дней)
  - Включение/отключение напоминаний
- **Улучшенный интерфейс курсов**: название и продолжительность сверху, кнопки снизу
- **Управление курсами**: редактирование, удаление, отметка приема
- **Автоматические напоминания** через системные уведомления (московское время)
- **Отслеживание оставшихся дней** курса
- **Исправлена логика**: создание курса не добавляет запись в историю

### 5. Система безопасности
- **Автоматический расчет** доз по весу с учетом концентрации препарата
- **Проверка превышения** максимальной разовой дозы
- **Контроль суточной дозировки** с цветовой индикацией
- **Интервалы между приемами** (4 часа для парацетамола, 6-8 для ибупрофена)
- **Предупреждения о продолжительности** лечения (более 3 дней)
- **Специальные предупреждения** о делении свечей
- **Ограничения по весу** для разных форм препаратов
- **Предупреждение о таблетках ибупрофена** для детей до 20кг или младше 6 лет

### 6. Отчеты и экспорт
- **PDF отчеты** с настраиваемыми параметрами:
  - Выбор периода (произвольные даты)
  - Выбор препаратов для включения
  - Статистика и графики
- **История наблюдений** с сортировкой по времени
- **Объединенная лента** температуры и лекарств

### 7. Образовательный контент
- **Статья 1**: "Важная информация при повышении температуры" (подробные рекомендации)
- **Статья 2**: "Первая помощь, если у ребенка судороги"
- **Встроенные рекомендации** при записи температуры

### 8. Уведомления
- **Системные напоминания** о приеме лекарств
- **Планирование уведомлений** на весь курс лечения
- **Автоматическая отмена** при удалении курса
- **Поддержка Android/iOS** уведомлений

## Технические особенности
- **Платформа**: Flutter Web с поддержкой мобильных устройств
- **Хранение данных**: SharedPreferences (локальное, без интернета)
- **График**: FL Chart с кастомными маркерами
- **Уведомления**: flutter_local_notifications + timezone (московское время)
- **PDF**: pdf пакет для генерации отчетов
- **Интернационализация**: Intl для дат и времени
- **Архитектура**: StatefulWidget с моделями данных

## Зависимости
- **flutter_localizations** - локализация
- **shared_preferences** - локальное хранение
- **fl_chart** - графики
- **intl** - форматирование дат
- **flutter_local_notifications** - уведомления
- **timezone** - работа с часовыми поясами
- **pdf** - генерация PDF
- **path_provider** - доступ к файловой системе
- **share_plus** - шаринг файлов
